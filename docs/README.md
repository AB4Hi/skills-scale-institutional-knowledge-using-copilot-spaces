# OctoAcme Project Management Docs

This repository contains the OctoAcme project management process documents. This README provides a short summary of our processes and direct links to each document in the docs/ folder.

## Summary

OctoAcme uses an iterative, customer-focused project delivery approach with clear ownership and lightweight artifacts. Core activities include:

- **Initiation**: Problem validation, stakeholder alignment, and one-pager creation
- **Planning**: Prioritized backlog, effort estimation, Definition of Done, and dependency mapping
- **Execution**: Sprint cadence, PR workflows, CI/CD checks, and daily standups
- **Release**: Pre-release verification, deployment checklists, and rollback plans
- **Continuous Improvement**: Retrospectives, action item tracking, and process refinement

Risk and communication practices ensure identified blockers are escalated through defined paths, and all team members have visibility into project status and decisions.

## How to Use These Docs

### Getting Started
- **New to OctoAcme?** Start with the [Project Management Overview](octoacme-project-management-overview.md) for a quick orientation on our principles, roles, and artifacts.

### Starting a New Project
- Use the [Project Initiation Guide](octoacme-project-initiation.md) to validate the business need and create your one-pager
- Follow the [Project Planning](octoacme-project-planning.md) guide to build your prioritized backlog and release plan

### During Delivery
- Reference the [Execution & Tracking](octoacme-execution-and-tracking.md) guide for sprint cadence, PR workflows, and quality expectations
- Check the [Risk Management & Communication](octoacme-risks-and-communication.md) guide for status reporting and escalation procedures

### Before Release
- Use the [Release & Deployment Guide](octoacme-release-and-deployment.md) checklists to verify readiness and plan your deployment

### After Release
- Facilitate a retrospective using the [Retrospective & Continuous Improvement](octoacme-retrospective-and-continuous-improvement.md) guide
- Capture and track action items to drive iterative process improvements
